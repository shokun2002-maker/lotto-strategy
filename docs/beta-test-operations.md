# LOTTO STRATEGY 무료 베타 테스트 운영 가이드 (7일 로드맵 & 개인정보 방침)

본 문서는 LOTTO STRATEGY 서비스의 1차 무료 베타 테스트 기간 동안의 **운영 로드맵, 테스터 구성 원칙, 피드백 분류 대응 원칙, 제1238회 추첨 데이터 업데이트 파이프라인 및 사용자 개인정보 보호 수칙**을 정리한 가이드라인입니다.

---

## 1. 베타 테스터 구성 및 모집 원칙

1. **권장 테스터 규모**: **5 ~ 10명** (소규모 집중 피드백 수집)
2. **권장 기기/환경 믹스**:
   - **아이폰 (iOS / Safari PWA)** 테스터 2~3명
   - **안드로이드 (Android / Chrome PWA)** 테스터 2~3명
   - **카카오 간편 로그인** 테스터 2명
   - **이메일 회원가입/로그인** 테스터 2명
   - **비로그인 Guest** 전용 이용 테스터 2명
3. **개인정보 보호 수칙**:
   - 프로젝트 문서, Git 저장소, 이슈 트래커 및 외부 노출 파일에 테스터의 실제 성명, 전화번호, 이메일 주소를 일절 포함하지 않습니다.
   - 피드백 접수 시 'FB-001'과 같은 익명 ID로만 기록합니다.

---

## 2. 7일간의 베타 테스트 운영 로드맵

| 일정 | 단계 | 세부 운영 활동 |
| :--- | :--- | :--- |
| **Day 1** | **초대 & 설치 확립** | `docs/beta-tester-kakao-message.md` 메시지 발송, 테스터별 Safari/Chrome PWA 홈 화면 추가 및 최초 접속 검증 |
| **Day 2 ~ 3** | **사용성 피드백 수집** | 테스터 자유 이용 (번호 추천, 내 번호 저장, 로그인, 클라우드 동기화, UI/UX 피드백 수집) |
| **Day 4** | **피드백 취합 & Severity 분류** | 접수된 피드백을 `docs/beta-feedback-log-template.md`에 기록하고 P0/P1/P2/P3 분석 |
| **Day 5 ~ 6** | **P0/P1 긴급 조치 & 재테스트** | P0/P1 결함 발생 시 최소 범위 보완 후 프로덕션 검증 (단 순수 취향성 P3는 과도한 변경 배제) |
| **Day 7** | **1차 베타 결과 종합 보고** | 1차 베타 운영 결산 및 정식 오픈 준비도 평가 |

---

## 3. 피드백 대응 및 패치 원칙

- **P0 (Critical / Blocker)**: 즉시 베타 테스트 일시 중단 검토 후 원인 파악 및 최우선 핫픽스 수행.
- **P1 (High)**: 최우선 수정 대상으로 지정하여 로컬 검증 후 프로덕션 반영.
- **P2 (Medium)**: 재현 가능 여부 및 영향도를 파악한 후 패치 여부 결정.
- **P3 (Low / UX Proposal)**: 한 사람의 주관적 취향에 따라 UI를 즉시 전면 변경하지 않으며, 동일한 피드백이 다수 수집되는 경우에 한해 UX 개선 사이클에 반영.

---

## 4. 제1238회 차기 추첨 데이터 업데이트 운영 가이드

베타 테스트 진행 기간 중 매주 토요일 로또 추첨(제1238회: 2026-08-22 예정)이 완료되면 기존 프로젝트 운영 절차에 따라 다음을 수행합니다.

1. **상태 검크 스크립트 실행**:
   ```bash
   npm run lotto:check
   ```
2. **`UPDATE_AVAILABLE` 확인 시 데이터 파이프라인 수행**:
   ```bash
   npm run lotto:update
   npm run lotto:validate
   npm run lotto:regression
   ```
3. **무결성 검증 후 반영**:
   - `src/data/lotto-draws.json`에 제1238회 추첨 결과가 정밀하게 추가되었는지 확인 후 빌드 검증 수행.
   - 테스터 운영 기간 중에도 로또 추첨 데이터 업데이트 파이프라인 수칙을 임의 변경하지 않음.

---

## 5. 결제 (Billing) 안내 원칙

- 현재 `BILLING_AVAILABILITY = "under_review"` 상태를 엄격히 유지합니다.
- 베타테스터에게 어떠한 실결제도 요구하지 않으며, `/pro` 페이지 내 결제 기능은 정찰 상태 안내용으로 차단되어 있음을 무료 베타 안내문에 명시합니다.
