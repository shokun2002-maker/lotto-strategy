# LOTTO STRATEGY 베타 피드백 양식 (테스터 제출용)

불편하신 점이나 버그를 발견하셨다면 아래 양식을 복사하여 카카오톡 메시지로 보내주시면 서비스 개선에 큰 도움이 됩니다!

---

```text
[LOTTO STRATEGY 베타 피드백]

1. 스마트폰 종류 / 기종:
(예: 아이폰 15 / 갤럭시 S24 / 갤럭시 Z플립)

2. 사용 방식:
(예: Safari 앱 설치 / Chrome 앱 설치 / 일반 웹 브라우저)

3. 로그인 여부:
(예: 비로그인 Guest / 카카오 로그인 / 이메일 로그인)

4. 문제가 발생한 화면:
(예: 메인 홈 / 빠른 추천 / 전략 추천 / 내 번호 / MY 페이지)

5. 어떤 동작을 할 때 발생했나요?
(예: '전략 번호 생성' 버튼을 눌렀을 때)

6. 어떤 문제가 있었나요?
(예: 버튼을 눌러도 반응이 없음 / 글자가 밖으로 튀어나옴 / 오류 메시지가 뜸)

7. 다시 시도했을 때 또 발생하나요?
(항상 발생 / 가끔 발생 / 한 번만 발생)

8. 캡처 화면 첨부 여부:
(첨부함 / 첨부 안 함)

9. 기타 의견 및 서비스 개선 제안:
```
