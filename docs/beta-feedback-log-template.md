# LOTTO STRATEGY 운영자 피드백 기록표 (Log Template)

운영자는 접수된 테스터 피드백을 아래 서식에 맞춰 기록하고 Severity를 분류하여 체계적으로 관리합니다.

---

## 1. Severity 분류 기준 정의

- **P0 (Critical / Blocker)**:
  - 계정 간 데이터 유출 (타인의 저장 번호가 내 화면에 노출됨)
  - 사용자 데이터 무단 파기/영구 유실
  - Secret Key 또는 토큰 노출
  - 인증 완전 우회 또는 서비스 전체 사용 불가 장애
- **P1 (High)**:
  - 로그인 / 카카오 OAuth 전면 불가
  - 번호 추천 생성 및 저장 기능 전면 동작 불가
  - Cloud Sync 핵심 기능 붕괴
  - 특정 기기/브라우저 앱 연속 Crash
- **P2 (Medium)**:
  - 특정 조건에서 번호 생성 오류 또는 중복 표시
  - 특정 화면 레이아웃/모달 깨짐 (기능 사용은 가능)
  - UI 상태 표시 오류 (Sync 시간 표시 오류 등)
  - 심각하진 않으나 사용에 명확한 불편 발생
- **P3 (Low / UX Proposal)**:
  - 문구 오탈자, 마진/여백/색상 스타일 다듬기
  - 사소한 UI 개선 제안 및 피처 아이디어

---

## 2. 피드백 관리 상태 (Status) 정의

- `NEW`: 새로 접수되어 분석 대기 중
- `CONFIRMED`: 이슈 재현 성공 및 결함 확정
- `IN_PROGRESS`: 수정 작업 진행 중
- `FIXED`: 수정 완료 및 로컬 검증 완료
- `RETEST`: 프로덕션 반영 후 재검증 진행 중
- `CLOSED`: 검증 완료 및 조치 종료
- `WONT_FIX`: 스펙 의도 동작 또는 수용 불가 제안
