# LOTTO STRATEGY 스마트폰 홈 화면 앱 설치 가이드 (PWA)

LOTTO STRATEGY 서비스는 별도의 앱스토어 다운로드 없이, 사용 중이신 스마트폰(아이폰/안드로이드)의 홈 화면에 웹 앱(PWA)을 설치하여 주소창 없는 독립형(Standalone) 앱으로 편리하게 사용할 수 있습니다.

---

## 📱 [아이폰 / iOS 사용자 설치 방법]

> ⚠️ **주의**: 카카오톡 등 앱 내부 브라우저에서는 "홈 화면에 추가" 메뉴가 지원되지 않을 수 있습니다. 반드시 **Safari 브라우저**로 접속해 주세요.

1. **카카오톡 링크 열기**: 카카오톡으로 받은 링크를 누른 후, 우측 하단 `···` (또는 공유 아이콘) $\rightarrow$ **'Safari로 열기'** 선택.
2. **Safari 공유 버튼 클릭**: Safari 하단 중앙의 **공유 버튼**([↑] 모양 아이콘)을 누릅니다.
3. **홈 화면에 추가**: 메뉴 목록을 아래로 스크롤하여 **'홈 화면에 추가'** 항목을 누릅니다.
4. **설치 완료**: 우측 상단 **'추가'** 버튼을 누르면 스마트폰 홈 화면에 **LOTTO STRATEGY** 파란색 아이콘이 생성됩니다.
5. **실행**: 홈 화면 아이콘을 누르면 주소창 없이 앱처럼 즉시 실행됩니다.

---

## 🤖 [안드로이드 / Android 사용자 설치 방법]

1. **카카오톡 링크 열기**: 카카오톡으로 받은 링크를 누른 후, 우측 하단 `⋮` (또는 다른 브라우저로 열기) $\rightarrow$ **'Chrome으로 열기'** 선택.
2. **Chrome 메뉴 클릭**: Chrome 우측 상단 메뉴 점 3개(`⋮`) 아이콘을 누릅니다.
3. **앱 설치 / 홈 화면에 추가**: **'앱 설치'** 또는 **'홈 화면에 추가'** 메뉴를 누릅니다.
4. **확인**: 팝업창에서 **'설치'** 또는 **'추가'**를 누르면 홈 화면 및 앱스토어 아이콘 목록에 **LOTTO STRATEGY** 아이콘이 추가됩니다.
5. **실행**: 아이콘을 누르면 독립 실행형 모드(Standalone)로 앱이 시작됩니다.

---

## 💡 [자주 묻는 질문 (FAQ)]

- **Q. 카카오톡에서 바로 설치 버튼이 보이지 않나요?**
  - 카카오톡 인앱 브라우저는 보안 정책상 PWA 설치 기능을 제한합니다. 상단/하단 메뉴를 통해 Safari 또는 Chrome으로 연결하여 설치해 주세요.
- **Q. 오프라인에서도 사용할 수 있나요?**
  - 기존에 생성 및 저장한 번호 목록은 인터넷이 끊겨도 로컬 저장소(LocalStorage)를 통해 확인할 수 있습니다. 단, 최신 회차 추첨 데이터 업데이트 및 클라우드 동기화는 인터넷 연결이 필요합니다.
