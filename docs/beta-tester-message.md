[LOTTO STRATEGY 무료 베타 테스터 초대 🎟️]

안녕하세요! 과거 로또 6/45 데이터를 기반으로 통계 분석과 나만의 맞춤형 전략 번호를 만들어보는 **LOTTO STRATEGY** 무료 베타 서비스가 오픈되었습니다! 🥳

스마트폰 홈 화면에 앱으로 설치하여 언제든 편리하게 이용해 보세요.

🔗 **베타 접속 링크**: https://lotto-strategy.vercel.app

📲 **스마트폰 앱(PWA) 설치 방법**:
1. 링크 접속 후 Safari(아이폰) 또는 Chrome(안드로이드)으로 열기
2. [공유] $\rightarrow$ [홈 화면에 추가] 또는 [앱 설치] 선택!
3. 홈 화면의 파란색 LOTTO STRATEGY 아이콘 클릭!

✨ **주요 기능**:
- 과거 공개 데이터 기반 출현/미출현/밸런스 번호 조합 추천
- 내 커텀 전략 저장 및 번호 자동 생성
- 카카오/이메일 로그인으로 클라우드 안전 동기화

💡 사용해 보시고 불편하신 점이나 아이디어가 있다면 편하게 의견 부탁드립니다!
