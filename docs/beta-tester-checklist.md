# LOTTO STRATEGY 베타테스터 체크리스트

본 체크리스트는 LOTTO STRATEGY 무료 베타 서비스의 주요 기능을 테스터분들이 직관적으로 시험해 보실 수 있도록 안내하는 항목입니다.

---

## 1. 앱 설치 및 기본 접속
- [ ] 링크(https://lotto-strategy.vercel.app)로 접속 시 메인 화면이 깔끔하게 표시되는지
- [ ] 아이폰 Safari 또는 안드로이드 Chrome에서 '홈 화면에 추가(앱 설치)'가 정상 작동하는지
- [ ] 홈 화면에 생긴 **LOTTO STRATEGY** 파란색 아이콘을 눌렀을 때 주소창 없는 앱 모드(Standalone)로 시작되는지
- [ ] 스마트폰 화면을 세로/가로로 볼 때 글자가 잘리거나 버튼이 밀리지 않는지

## 2. 번호 추천 기능
- [ ] **빠른 추천**: 6개 로또 번호가 1~45 범위 내에서 오름차순으로 중복 없이 잘 생성되는지
- [ ] **같이 선택**: 내가 고른 고정수/제외수를 반영하여 남은 번호가 잘 조합되는지
- [ ] **전략 추천**: 균형형, 최근 트렌드, 장기 미출현 등 전략별로 번호가 정상 생성되는지

## 3. 번호 저장 및 내 번호 관리
- [ ] 생성된 추천 번호를 '저장하기' 눌렀을 때 성공 안내 메시지가 나오는지
- [ ] 하단 메뉴 **'내 번호'** 탭에서 저장한 번호 목록이 회차별로 잘 표시되는지
- [ ] 앱을 완전히 종료했다가 다시 켜도 내가 저장한 번호가 그대로 유지되는지
- [ ] 저장한 번호를 삭제하려고 할 때 실수 방지 안내창이 뜨고 삭제가 정상 처리되는지

## 4. 로그인 및 클라우드 동기화
- [ ] 카카오톡 로그인 또는 이메일 회원가입/로그인이 문제없이 진행되는지
- [ ] 비로그인(Guest) 상태에서 저장했던 번호가 로그인 후에도 내 계정으로 잘 옮겨오는지
- [ ] 로그아웃 후 다시 로그인했을 때 저장한 번호와 전략이 그대로 복원되는지

## 5. 사용성 및 디자인 피드백
- [ ] 버튼이 너무 작아서 누르기 불편한 곳이 있는지
- [ ] 무슨 뜻인지 이해하기 힘든 어려운 단어나 문구가 있는지
- [ ] 화면 전환이나 번호 생성 속도가 답답하게 느껴지는 곳이 있는지
